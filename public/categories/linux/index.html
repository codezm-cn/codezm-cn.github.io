Linux安装过程记录（Ubuntu版本）

安装信息如下：

系统版本：Ubuntu-22.04.4-live-server-amd64

点击链接下载镜像（清华镜像源）

虚拟机版本：VMware WorkStation 17.5

其他版本可能有所区别，仅供参考

虚拟机参数配置：

内容 参数
内存 4GB
处理器数量 2
内核总数 4
硬盘 10GB
网络 NAT（后续视情况更改）

安装过程

  • Try or Install Ubuntu Serve(默认，直接选)

  • Ubuntu Server with the HWE kernel(涉及新硬件等内容，虚拟机不选)

  • English

  • Continue without updating

  • Ubuntu server

  • Ubuntu server(minimized)

最小安装，不方便后续使用，不推荐

  • search for third-party drivers

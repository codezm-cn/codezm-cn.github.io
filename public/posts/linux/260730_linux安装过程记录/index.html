Linux安装过程记录（Ubuntu版本）

July 30, 2026

安装信息如下：

系统版本：Ubuntu-22.04.4-live-server-amd64

点击链接下载镜像（清华镜像源）

虚拟机版本：VMware WorkStation 17.5

其他版本可能有所区别，仅供参考

虚拟机参数配置：

内容 参数
内存 4GB
处理器数量 2
内核总数 4
硬盘 10GB
网络 NAT（后续视情况更改）

安装过程

  • Try or Install Ubuntu Serve(默认，直接选)

  • Ubuntu Server with the HWE kernel(涉及新硬件等内容，虚拟机不选)

  • English

  • Continue without updating

  • Ubuntu server

  • Ubuntu server(minimized)

    最小安装，不方便后续使用，不推荐

  • search for third-party drivers

推荐使用清华源

http://mirrors.tuna.tsinghua.edu.cn/ubuntu/

其他源推荐(阿里云、中科大、网易)

http://mirrors.aliyun.com/ubuntu/
http://mirrors.ustc.edu.cn/ubuntu/
http://mirrors.163.com/ubuntu/

安装截图那边带s（https）发现用不了，后修改为http（内网代理对 HTTP 的支持更完善，能有效避免 400 错误）

此时系统提示确认后无法返回重新配置，直接点continue

有个Ubuntu pro安装，直接忽略

  • Install OnenSSH server(便于后续使用客户端使用)

建议跳过，后续根据需求再安装

显示Reboot Now就是安装完成了！

附录：软件安装页的软件是什么(来自AI，仅供参考)

软件 是什么？ 是否需要？
microk8s 轻量级 Kubernetes（容器编排） ❌ 不需要（太高级）
nextcloud 自建网盘服务 ❌ 不需要（学习阶段）
wekan 看板工具 ❌ 不需要
canonical-livepatch Ubuntu 的内核热补丁 ⚠️ 可选（生产环境用）
rocketchat-server 即时通讯服务器 ❌ 不需要
mosquitto MQTT 消息代理 ✅ 未来有用（物联网相关）
etcd 分布式键值存储 ❌ 不需要
powershell Windows PowerShell for Linux ❌ 不需要
sabnzbd 下载工具 ❌ 不需要
wormhole 文件传输工具 ❌ 不需要
aws-cli, google-cloud-sdk 云平台命令行工具 ⚠️ 后期学习云计算时有用
slicl, doctl 云服务商工具 ❌ 当前不需要
keepalived 高可用 VIP（类似 VRRP） ✅ 以后学高可用/负载均衡会用到
prometheus 监控系统 ✅ 学习监控时有用

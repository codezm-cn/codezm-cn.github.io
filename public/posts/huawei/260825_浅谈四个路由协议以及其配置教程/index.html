常见路由协议简介与要点

1. RIP

全称路由信息协议，Routing Information Protocol

其使用跳数（Hop Count）来衡量到达目的地址的距离，称为度量值。在缺省情况下，路由设备到与它直接相连网络的跳数为0，通过一个路由设备可达的网络的跳数为1。也就是说，度量值等于从本网络到达目的网络间的路由设备数量。

为限制收敛时间，RIP规定度量值取0～15之间的整数，大于或等于 16 的跳数被定义为目的网络或主机不可达（Network Unreachable）。由于这个限制，使得RIP不可能在大型网络中得到应用。

RIP 路由器默认每 30 秒使用UDP520端口发送一次路由表，如果在 180 秒之内没有收到路由的更新，则将该路由置为无效，在 120 秒内还没收到这条路由的更新，就从路由表中将该路由删除。

2. OSPF

全称开放式最短路径优先，Open Shortest Path First

其通过在自治系统（AS，autonomous system）中划分区域（骨干、普通、末梢STUB）和选举主备路由器DR和BDR，利用Dijkstra最短路径算法生成最短路径树，建立并维护链路状态数据库（LSDB,Link State Database）。

OSPF用IP报文直接封装协议报文，协议号为89。OSPF分为5种报文：Hello报文、DD报文、LSR报文、LSU报文和LSAck报文，翻译下来分别是哈喽报文、数据库描述报文、链路状态请求报文、链路状态更新报文、链路状态确认报文。

注意区分LSA（链路状态通告）和LSAck，LSA是链路状态信息，被封装在DD、LSU报文中传递；LSR用来请求LSA，LSAck用来确认LSA。

3. IS-IS

全称中间系统到中间系统，Intermediate system to intermediate system

其特性与OSPF有一定关系：是一种链路状态协议，使用最短路径优先SPF算法进行路由计算，选举DIS和非DIS（与OSPF中的DR和BDR类似）。

分为三种路由器：L1路由器、L2路由器和L1/L2路由器。其中，L1路由器是为端系统直接提供服务的路由器，L2路由器是骨干路由器。L1/L2 路由器负责把 L1 区域的路由泄露/汇总进 L2 骨干，同时向 L1 区域自动下发一条默认路由，形似桥梁。

分为三种报文：HELLO PDU（Protocol Data Unit）、LSP（Link State PDUs）和SNP（Sequence Number PDUs）翻译为Hello报文、链路状态报文、序列号报文。

适用于大型运营商。

4. BGP

全称边界网关协议，Border Gateway Protocol

其使用TCP179端口作为其传输层协议，通过自治系统（AS）的内外关系分为内部（Internal）BGP和外部（External）BGP，也就是常说的IBGP、EBGP。

5. 分类与关系

分类如下图所示：

特性 OSPF RIP BGP
协议类型 链路状态协议 距离矢量协议 路径矢量协议
承载协议 IP UDP(520) TCP(179)
路由算法 Dijkstra算法 距离矢量算法 路径向量算法
路由更新机制 链路状态变化时触发更新 周期性更新(30秒)，变化时触发更新 增量更新，仅在路由变化时发送
路由表维护 维护完整LSDB 维护完整路由表 仅维护最优路由表
防环机制 SPF算法 水平分割、毒性逆转 AS路径检查
度量标准 成本(Cost，基于带宽) 跳数(Hop Count) AS路径长度、本地优先级等
网络规模 中大型网络(数百台路由器) 小型网络(≤15跳) 超大型网络(互联网级)
收敛速度 快 慢 较慢
路由更新开销 中等(仅更新变化部分) 高(发送完整路由表) 低(增量更新)

#主要：RIP配置
[AR1]rip 65535    #配置rip，数字自定（限制1-65535），建议保持一致
[AR1-rip-65535]version 2    #启用RIPv2，v1协议存在安全风险
[AR1-rip-65535]network 192.168.1.0    #宣告网段，将该设备所连接的网段进行宣告（无主机号）
[AR1-rip-65535]network 1.1.1.0
Error: The network address is invalid, and the specified address must be major-n
et address without any subnets.
#解释：宣告网络是主类网络号，不能是子网地址，需要根据子网类型进行设置
#如A类10.0.0.0，B类172.16.0.0，C类192.168.1.0
[AR1-rip-65535]network 1.0.0.0
[AR1-rip-65535]quit

[AR2]rip 65535
[AR2-rip-65535]network 1.0.0.0
[AR2-rip-65535]network 2.0.0.0
[AR2-rip-65535]quit

[AR3]rip 65535
[AR3-rip-65535]network 2.0.0.0
[AR3-rip-65535]network 172.16.0.0
[AR3-rip-65535]quit

此时使用PCping可以互通，或在路由器使用 display ip routing-table 可以查看路由表

在后面加protocol 协议类型可以筛选对应的路由表如 display ip routing-table protocol rip

OSPF的配置

拓扑图如图所示：

其中AR 2中的GE 1/0/0口是外加接口卡，由于AR1220设备只有2个GE口，且E口默认工作在二层模式（本质是交换口），不能直接配置IP地址，也不能使用undo portswitch命令，所以可以右键该设备，点击设置进入视图界面添加接口卡

IP配置忽略，下面是ospf的主要配置：

[AR1]ospf 1    #数字自定义，最高65535，建议和其他路由保持一致
[AR1-ospf-1]area 0    #根据划分输入数字，骨干区域必须为0
[AR1-ospf-1-area-0.0.0.0]network 1.0.0.0 0.255.255.255    
#宣告这个区域所直连的网段，并且需要补充反掩码，反掩码的输入见下方引用
[AR1-ospf-1-area-0.0.0.0]area 1
[AR1-ospf-1-area-0.0.0.1]network 10.0.0.0 0.255.255.255
[AR1-ospf-1-area-0.0.0.1]quit    #需要quit2次


[AR2]ospf 1
[AR2-ospf-1]area 0
[AR2-ospf-1-area-0.0.0.0]network 1.0.0.0 0.255.255.255
[AR2-ospf-1-area-0.0.0.0]network 2.0.0.0 0.255.255.255
[AR2-ospf-1-area-0.0.0.0]network 3.0.0.0 0.255.255.255
[AR2-ospf-1-area-0.0.0.0]quit

[AR3]ospf 1
[AR3-ospf-1]area 0
[AR3-ospf-1-area-0.0.0.0]network 2.0.0.0 0.255.255.255
[AR3-ospf-1-area-0.0.0.0]area 2
[AR3-ospf-1-area-0.0.0.2]network 20.0.0.0 0.255.255.255
[AR3-ospf-1-area-0.0.0.2]quit

[AR5]ospf 1
[AR5-ospf-1]area 1
[AR5-ospf-1-area-0.0.0.1]network 10.0.0.0 0.255.255.255
[AR5-ospf-1-area-0.0.0.1]network 192.168.1.0 0.0.0.255
[AR5-ospf-1-area-0.0.0.1]quit


[AR6]ospf 1
[AR6-ospf-1]area 2
[AR6-ospf-1-area-0.0.0.2]network 20.0.0.0 0.255.255.255
[AR6-ospf-1-area-0.0.0.2]network 172.16.0.0 0.0.255.255
[AR6-ospf-1-area-0.0.0.2]quit

反掩码顾名思义将掩码转换为二进制后取反（0变1，1变0）

例子/30(255.255.255.252)

转换为2进制->1111 1111.1111 1111.1111 1111.1111 1100,

其反掩码为0000 0000.0000 0000.0000 0000.0000 0011

转换为十进制->0.0.0.3

此时设备可以互相ping通，使用命令 display ip routing-table 查看路由表，display ospf peer查看OSPF邻居关系，display ospf lsdb查看链路状态数据库

[AR1]isis 1    #进入isis模式，数字自定义，建议和其他路由保持一致
[AR1-isis-1]network-entity 49.0001.0000.0000.0001.00    #设置NET，格式见引用
[AR1-isis-1]is-level level-1-2    #设置等级，默认为level-1-2
[AR1-isis-1]quit
[AR1]int g 0/0/0

网络实体名NET（Network Entity Title）的格式为：AFI.Area ID.System ID.SEL

AFI（地址族标识 Address Family Identifier）:私有网络为49（推荐），或演示为10

Area ID:根据规划定义，如0001，0002

需要L2 邻居的Area ID 可以不同；L1 邻居的Area ID 必须相同（也就是说图中AR1与AR5必须一致，AR3与AR6必须一致）因为刚开始乱配发现ping不通才发现的问题

System ID:自定义但唯一，可以用Router-Id转换（1.1.1.1->0010.0100.1001），或直接按序号（0000.0000.0001）甚至可以用Loopback环回地址转换（172.16.1.1->1720.1600.1001）

SEL：默认为00

BGP的配置

拓扑图如图：

BGP的配置如下，其中IP配置、AS 100的RIP宣告、AS 200静态路由配置已忽略：

为便于查看AS 100的IP与rip配置已写入文档，点击查看

#AS 100
[AR1]bgp 100    #进入BGP
[AR1-bgp]peer 100.1.1.1 as-number 100    #将邻接的IP归入AS内
[AR1-bgp]peer 101.1.1.2 as-number 100
[AR1-bgp]import-route rip 1
#方案A：将RIP宣告的路由引入BGP，带标号
[AR1-bgp]quit
[AR1]rip 1
[AR1-rip-1]import-route bgp    #互相引用，不带标号
[AR1-rip-1]quit

[AR2]bgp 100
[AR2-bgp]peer 101.1.1.1 as-num 100
[AR2-bgp]peer 100.1.2.1 as-num 100
[AR2-bgp]quit
[AR2]rip 1
[AR2-rip-1]import bgp
[AR2-rip-1]quit
[AR2]bgp 100
[AR2-bgp]import rip 1
[AR2-bgp]quit

[AR3]bgp 100
[AR3-bgp]peer 100.1.1.2 as-n 100
[AR3-bgp]peer 100.1.2.2 as-n 100
[AR3-bgp]peer 1.1.1.2 as-n 200
[AR3]bgp 100
[AR3-bgp]imp rip 1
[AR3-bgp]rip 1
[AR3-rip-1]imp bgp
[AR3-rip-1]quit

#AS 200
[AR4]bgp 200
[AR4-bgp]peer 1.1.1.1 as-n 100
[AR4-bgp]peer 10.1.1.2 as-n 200
[AR4-bgp]network 10.1.1.0 255.0.0.0
#方案B：直接宣告（精确匹配），IP和掩码（注意区分OSPF的反掩码）
[AR4-bgp]network 1.0.0.0 255.0.0.0
[AR4-bgp]quit

[AR5]bgp 200
[AR5-bgp]peer 10.1.1.1 as-n 200
[AR5-bgp]network 172.16.0.0 255.255.0.0
[AR5-bgp]network 10.1.1.0 255.0.0.0
[AR5-bgp]quit

BGP高级用法较多，这里只做简单演示

使用 display ip routing-table 查看路由表会发现只有EBGP和其他路由协议，因为BGP的优先级极低（默认255），因此会被其他协议覆盖

可以通过以下命令查看BGP相关属性：

  • display bgp peer:查看邻居
  •  display bgp routing-table:查看路由

结语

第一次写长文案，如有错误，欢迎到issue指正，感谢！

本次配置都是偏基础的，并适当结合中级网络工程师考点进行整理，复杂配置和资料可查阅其他文档

大部分命令采用简写形式，完整形式向上翻可以看到，第一次敲的是完整代码

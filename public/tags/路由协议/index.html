路由协议

August 29, 2026

浅谈四个路由协议（RIP,OSPF,IS-IS,BGP）以及其配置教程

常见路由协议简介与要点

1. RIP

全称路由信息协议，Routing Information Protocol

其使用跳数（Hop Count）来衡量到达目的地址的距离，称为度量值。在缺省情况下，路由设备到与它直接相连网络的跳数为0，通过一个路由设备可达的网络的跳数为1。也就是说，度量值等于从本网络到达目的网络间的路由设备数量。

为限制收敛时间，RIP规定度量值取0～15之间的整数，大于或等于 16 的跳数被定义为目的网络或主机不可达（Network Unreachable）。由于这个限制，使得RIP不可能在大型网络中得到应用。

RIP 路由器默认每 30 秒使用UDP520端口发送一次路由表，如果在 180 秒之内没有收到路由的更新，则将该路由置为无效，在 120 秒内还没收到这条路由的更新，就从路由表中将该路由删除。

2. OSPF

全称开放式最短路径优先，Open Shortest Path First

其通过在自治系统（AS，autonomous system）中划分区域（骨干、普通、末梢STUB）和选举主备路由器DR和BDR，利用Dijkstra最短路径算法生成最短路径树，建立并维护链路状态数据库（LSDB,Link State Database）。

OSPF用IP报文直接封装协议报文，协议号为89。OSPF分为5种报文：Hello报文、DD报文、LSR报文、LSU报文和LSAck报文，翻译下来分别是哈喽报文、数据库描述报文、链路状态请求报文、链路状态更新报文、链路状态确认报文。

注意区分LSA（链路状态通告）和LSAck，LSA是链路状态信息，被封装在DD、LSU报文中传递；LSR用来请求LSA，LSAck用来确认LSA。

3. IS-IS

全称中间系统到中间系统，Intermediate system to intermediate system

其特性与OSPF有一定关系：是一种链路状态协议，使用最短路径优先SPF算法进行路由计算，选举DIS和非DIS（与OSPF中的DR和BDR类似）。

分为三种路由器：L1路由器、L2路由器和L1/L2路由器。其中，L1路由器是为端系统直接提供服务的路由器，L2路由器是骨干路由器。L1/L2 路由器负责把 L1 区域的路由泄露/汇总进 L2 骨干，同时向 L1 区域自动下发一条默认路由，形似桥梁。

分为三种报文：HELLO PDU（Protocol Data Unit）、LSP（Link State PDUs）和SNP（Sequence Number PDUs）翻译为Hello报文、链路状态报文、序列号报文。

适用于大型运营商。

4. BGP

全称边界网关协议，Border Gateway Protocol

其使用TCP179端口作为其传输层协议，通过自治系统（AS）的内外关系分为内部（Internal）BGP和外部（External）BGP，也就是常说的IBGP、EBGP。

特性 OSPF RIP BGP
协议类型 链路状态协议 距离矢量协议 路径矢量协议

路由算法 Dijkstra算法 距离矢量算法 路径向量算法
